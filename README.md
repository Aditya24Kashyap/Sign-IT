# Signature App Sign-IT

A simple and elegant **Signature Drawing Web App** built using **HTML, CSS, and JavaScript**.  
Users can draw signatures, change pen size & color, and save/retrieve their signature.

---

## 🚀 Features

- 🖊️ Draw smooth signatures using mouse
- 🎨 Change pen color
- 📏 Adjust pen size
- 💾 Save signature as image (PNG)
- 🔁 Retrieve saved signature from localStorage
- 🌙 Dark Mode toggle (Gunpowder theme)
- ☀️ Light Mode support
- 🧹 Clear canvas
- 📱 Responsive UI

---

## 🖥️ Tech Stack

- **HTML5** – Structure
- **CSS3** – Styling & themes
- **JavaScript (Vanilla)** – Logic & canvas drawing
- **Bootstrap** – UI components
